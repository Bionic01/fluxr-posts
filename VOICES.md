Owner: Rodney. Started 1 Oct 2026. The daily routine reads this file with PLAYBOOK.md.

## What the user asked for (1 Oct 2026)

- Mix the voices to find out which one people respond to: female and male, and different kinds of male and female voices.
- In every 7 days, use the main voice on 4 videos and test other voices on the other 3.
- When a voice clearly does better, tell the user, and with their OK it becomes the main voice. Keep testing new voices on the other 3 slots.
- Voices must suit the African market (southern African accents) and must not sound like AI. No random American or British voices.

## Weekly rotation (7 evening videos)

- **4 main slots.** Until a winner is found, the main slots alternate between the two current favourites, Thobeka Majola and Darius Voice (2 each).
- **3 test slots.** Use 3 different voices from the test pool, and mix female and male. Don't use the same test voice twice in a week. Spread the test slots across different days and countries, not all on weekend days.
- **Order.** Plan the week's 7 voices on Monday and write them in the log, so the mix is deliberate.
- **Model and style.** Use eleven_v4 with light direction tags ([warmly], [excited], [long pause]). Write the brand as /ˈflʌksə/ so it is said "flux-er".
- **Check before using a new voice.** Generate the script, transcribe it, and confirm it is clear and "Fluxr" sounds like "flux-er". Send the voice with the day's review message so the user can hear it before saying "post". If the user says a voice sounds like AI, drop it from the pool.

## How to score the voices

- After 3 days, pull each video's results from Metricool for every platform it went to (TikTok, Instagram Reel, Facebook Reel, YouTube Short): views/plays, average watch time or completion, likes, comments, shares and saves. Add cost per WhatsApp chat or per click if the video ran as an ad.
- Compare voices on these two measures:
  - **Engagement rate:** interactions ÷ views.
  - **Watch time:** average watch time or completion.
- Countries and ideas change every day, so compare voices across the same weeks. Don't call a winner until a voice has at least 3 videos and is ahead on both measures.
- **Every Monday briefing:** send the user a short voice scoreboard (table plus one line on who is leading) and recommend whether to change the main voice. Change it only after the user says yes.
- **Don't wait to be asked (user, 1 Oct 2026).** Check the voice numbers in every morning briefing. As soon as one voice is clearly ahead (3+ videos, ahead on both measures), tell the user that day without being asked: "This voice is working best, let's use it more," with the numbers. Do the same if a voice is clearly doing badly and should be dropped.
